# Azure Support Labs

## Goal

Build practical Microsoft Azure support skills alongside the Coursera
**Microsoft Cloud Support Associate Professional Certificate**.

Current learning position:
- Courses 1-7 completed
- Course 8: Azure Cloud Services — in progress

## Learning Method

Every important topic follows this cycle:

**Topic → Build → Observe → Break → Diagnose → Fix → Verify → Delete**

The goal is not only to create Azure resources, but to understand:
- what Azure created;
- how resources depend on each other;
- what can fail;
- how to diagnose the failure;
- how to restore service safely.

## Scope

Main focus:
- Azure resource management
- Compute
- Networking
- Identity and RBAC
- Monitoring
- Backup and recovery
- Security and compliance
- Cloud support troubleshooting

## Lab Environment

Use real Microsoft Azure resources whenever practical.

Labs should:
- use low-cost resources;
- keep resource names easy to recognize;
- delete temporary resources after completion;
- avoid leaving paid resources running unnecessarily.

## Cost Safety

Before larger labs:
1. Check Azure Cost Management.
2. Keep a small monthly budget alert.
3. Prefer low-cost/free-tier resources.
4. Delete the complete lab Resource Group after the lab unless persistence is required.

Important: budget alerts do not automatically stop Azure resources.

## Expected Result

By the end of Courses 7-12, the project should provide:
- practical Azure experience;
- a set of completed support-oriented labs;
- troubleshooting examples;
- a clear Azure knowledge map;
- preparation for AZ-900;
- a foundation for later AZ-104 study.
